# Static assets

Files in this folder are served from the site root by Vite.

## cover.jpg (required)

The student homepage hero loads the cover image from `/cover.jpg`.
Add the banner image here named exactly `cover.jpg`:

```
public/cover.jpg
```

A wide landscape banner (roughly 851×315 or similar aspect ratio) works best.
Until the file is added, the hero image area will show a broken-image icon.
